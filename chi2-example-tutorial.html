Chi-Square Test of Independence: A Worked Example

A self-paced lesson on testing whether two categorical variables are related

A step-by-step, self-paced walkthrough of the chi-square test of independence, using a fictional evaluation of three math programs. Includes a reference table of chi-square critical values.

What you will learn

By the end of this lesson you will be able to:

  • Explain what a chi-square test of independence is used for.
  • State a null hypothesis and an alternative hypothesis for a chi-square test.
  • Calculate expected values from a table of counts.
  • Calculate the chi-square statistic, one cell at a time.
  • Find the degrees of freedom and use a table to estimate a p-value.
  • Decide whether to reject or fail to reject the null hypothesis.

You do not need any background in statistics or programming. Everything in this lesson is arithmetic: adding, subtracting, multiplying, dividing, and squaring. A calculator or a spreadsheet is helpful but not required.

The big idea

Sometimes we want to know whether two categorical variables are related. A categorical variable is one whose values are categories rather than numbers, like a favorite color, a type of program, or a choice of route.

The chi-square test of independence (chi rhymes with sky) helps us decide between two possibilities:

  • The two variables are independent: knowing one cannot help you predict the other.
  • The two variables are dependent: knowing one can help you predict the other.

The scenario

Imagine a school district is evaluating three math curriculums:

Math Program A, Math Program B, and Math Program C. Every student studied under exactly one of the three programs. For this lesson we will set aside how students ended up in each program.

The district wants to know whether the math program is related to what students do after they graduate from high school. For each student, the district recorded one of four outcomes:

  • Full-time work
  • Technical school
  • College or university
  • Military service

The district collected data for two years, with nearly 24,000 students in total.

Research question: Does the math program students studied relate to their post-high-school outcome?

The hypotheses

Every statistical test begins with two competing statements called hypotheses.

  • Null hypothesis: There is no relationship. Post-high-school outcomes are independent of the math program.
  • Alternative hypothesis: There is a relationship. Post-high-school outcomes depend on the math program.

The test works by assuming the null hypothesis is true, and then asking how surprising our data would be if that were so. If the data would be very surprising, we reject the null hypothesis.

The data

The data is summarized in a cross tabulation, which is a table of counts. Each row is a math program and each column is an outcome. Each box in the table is called a cell, and each cell counts the students who share that row and that column.

For example, in the first year, 1,278 students studied Math Program A and then went on to full-time work.

The table has three kinds of totals, which you will use again and again:

  • A row total (right-hand column) is the number of students in one math program.
  • A column total (bottom row) is the number of students with one outcome.
  • The grand total (bottom-right corner) is the number of students overall.

The counts in the table, the numbers we actually saw, are called the observed values.

A word about matrices

A grid of numbers arranged in rows and columns is called a matrix. The core of each table above, without the totals, is a matrix with 3 rows and 4 columns. In this lesson you will build two more matrices of the same size. Doing the same calculation “for every cell in the matrix” is a pattern you will see often, especially once we move to Python.

The formula

Here is the formula for the chi-square statistic, which is often written as χ² or X²:

\[ \chi^2 = \sum_{i=1}^{n} \frac{(Observed_i - Expected_i)^2}{Expected_i} \tag{1}\]

In plain words, for each cell:

  1. Subtract the expected value from the observed value.
  2. Square that difference.
  3. Divide by the expected value.

Then add up the results from every cell. The symbol Σ (sigma) means “add up,” and the little i simply means “for each cell, one at a time.”

You already have the observed values. The next step is to find the expected values.

Step 1: Calculate the expected values

What is an expected value?

An expected value answers this question: if the null hypothesis were true and there were no relationship, how many students would we expect to see in this cell?

If the math program made no difference, then each program would send students to each outcome in the same proportions as the group overall. The expected values capture exactly that.

The recipe

For each cell:

\[ Expected = \frac{Row\ Total \times Column\ Total}{Grand\ Total} \tag{2}\]

In the examples below, the rings show which numbers to use:

  • cell the cell you are working on
  • row total that cell’s row total
  • column total that cell’s column total
  • grand total the grand total

Worked example 1: Math Program A, Full-Time Work

\[ Expected = \frac{3867 \times 3875}{11919} = \frac{14{,}984{,}625}{11919} = 1257.205 \tag{3}\]

If there were no relationship, we would expect about 1,257 students in this cell. We actually observed 1,278.

Worked example 2: Math Program B, Technical School

\[ Expected = \frac{3951 \times 4664}{11919} = \frac{18{,}427{,}464}{11919} = 1546.058 \tag{4}\]

Notice that the recipe never changes. Only the row and column you look up change as you move from cell to cell.

The full matrix of expected values

Repeat the recipe for all 12 cells to get the expected values for the first year.

Check your work

The expected values in each row should add up to that row’s total, and the expected values in each column should add up to that column’s total. For example, 1257.205 + 1513.188 + 750.430 + 346.177 = 3867, which is the row total for Math Program A. If your sums do not match, look for an arithmetic slip.

Step 2: Calculate the normalized errors

Next, compare each observed value with its expected value. For each cell, calculate:

\[ \frac{(Observed - Expected)^2}{Expected} \tag{5}\]

This quantity is sometimes called a normalized error. The difference (observed minus expected) is the error. Squaring it makes every error positive, so errors in opposite directions cannot cancel each other out. Dividing by the expected value puts each error in proportion to the size of its cell.

Notice that the expected matrix is used twice here: once to find the difference, and again to divide.

Worked example: Math Program A, Full-Time Work

  • Observed: 1278 (from Table 1)
  • Expected: 1257.205 (from Table 5)

\[ \frac{(1278 - 1257.205)^2}{1257.205} = \frac{(20.795)^2}{1257.205} = \frac{432.432}{1257.205} = 0.344 \tag{6}\]

A second example: Math Program B, Technical School

\[ \frac{(1525 - 1546.058)^2}{1546.058} = \frac{(-21.058)^2}{1546.058} = \frac{443.439}{1546.058} = 0.287 \tag{7}\]

Here the difference was negative, but squaring it made the result positive.

The full matrix of normalized errors

Large numbers point to cells where the observed count is far from what we would expect under no relationship. In year one, the two biggest contributors are in the College/University column: Program A sent fewer students to college than expected (682 versus about 750), and Program C sent more (873 versus about 796).

Step 3: Add them up to get the chi-square statistic

The chi-square statistic is the sum of all the normalized errors:

\[ \chi^2 = 0.344 + 1.706 + 6.240 + 0.029 + 0.467 + 0.287 + 0.099 + 0.080 + 1.538 + 0.552 + 7.481 + 0.012 \tag{8}\]

\[ \chi^2 = 18.8346 \tag{9}\]

That’s it. A few simple operations, repeated across the matrix, give us our chi-square statistic.

Rounding

If you add the rounded values above, you get 18.835. The value 18.8346 comes from carrying all the decimal places through each step. Small differences in the last decimal place are normal and do not change the conclusion.

Step 4: Find the degrees of freedom

To turn the chi-square statistic into a p-value, we need one more number, called the degrees of freedom (often written df). For a chi-square test of independence:

\[ df = (\text{number of rows} - 1) \times (\text{number of columns} - 1) \tag{10}\]

Count only the rows and columns of categories, not the totals. Our table has 3 math programs and 4 outcomes:

\[ df = (3 - 1) \times (4 - 1) = 2 \times 3 = 6 \tag{11}\]

Step 5: Find the p-value and make a decision

What a p-value tells you

The p-value is the probability of getting results as extreme as ours, or more extreme, if the null hypothesis were true. A small p-value means our data would be surprising in a world with no relationship.

We compare the p-value to a cutoff called the significance level. The conventional significance level is 0.05.

  • If the p-value is less than 0.05, we reject the null hypothesis and conclude there is a relationship.
  • If the p-value is 0.05 or greater, we fail to reject the null hypothesis. We do not have enough evidence of a relationship.

Using the table

The chi-square reference table (Table 11) at the end of this lesson lets you estimate the p-value. It is a right-tailed table: the column headings are p-values, and the numbers inside the table are chi-square statistics. Bigger chi-square statistics sit farther to the right, where the p-values are smaller.

To use it:

  1. Find the row that matches your degrees of freedom.
  2. Move across that row until you find where your chi-square statistic fits between two numbers.
  3. Read the p-values at the top of those two columns. Your p-value lies between them.

Year one result

Here is the row for 6 degrees of freedom:

Our chi-square statistic, 18.8346, is larger than every number in the row, even 18.548 under the 0.005 column. That means our p-value is smaller than 0.005. (The exact p-value is 0.00445.)

Decision for year one: The p-value is less than 0.05, so we reject the null hypothesis. In year one, there is evidence of a relationship between math program and post-high-school outcome.

Interpreting the two years together

The two years led to different conclusions. Year one showed evidence of a relationship, and year two did not. This is a useful reminder that one test on one set of data is not the final word. Results can differ from sample to sample, which is why repeating a study matters.

In a scenario such as this we might attribute the first year result as something that is known as an “implementation bump” or “implementation dip” which is a common result in observational field studies. Keep in mind, too, that a chi-square test tells you whether two variables are related. It does not, on its own, tell you that one caused the other.

Remember also that we set aside how students were placed into each program. If, for example, students who already planned on college tended to choose Program C, that alone could create a relationship in the data.

Other ways to get the p-value

The table gives you a range. Software can give you the exact p-value. In Excel, there are two functions for this.

CHISQ.TEST compares the observed values with the expected values and returns the p-value directly. You give it the observed range first and the expected range second:

=CHISQ.TEST(observed range, expected range)

CHISQ.DIST.RT converts a chi-square statistic into a p-value. You give it the chi-square statistic and the degrees of freedom:

=CHISQ.DIST.RT(chi-square statistic, degrees of freedom)

For year one, =CHISQ.DIST.RT(18.8346, 6) returns 0.00445.

In upcoming tutorials, you will learn to carry out this same analysis in Python. Every step you did by hand here, from the expected values to the final p-value, has a direct counterpart in code.

Summary

  1. State the null hypothesis (no relationship) and the alternative hypothesis (a relationship).
  2. Organize the observed counts in a cross tabulation with row, column, and grand totals.
  3. For each cell, calculate the expected value: row total × column total ÷ grand total.
  4. For each cell, calculate the normalized error: (observed − expected)² ÷ expected.
  5. Add up the normalized errors to get the chi-square statistic.
  6. Find the degrees of freedom: (rows − 1) × (columns − 1).
  7. Use the table (or software) to find the p-value.
  8. If the p-value is less than 0.05, reject the null hypothesis. Otherwise, fail to reject it.

Reference: Chi-square critical values

Find the row for your degrees of freedom. The column headings are right-tail p-values. If your chi-square statistic falls between two numbers in the row, your p-value falls between the two column headings.

# Use scipy to create a table of p-values based on critical values and df
from scipy import stats

p_values = [0.995, 0.99, 0.975, 0.95, 0.90, 0.10, 0.05, 0.025, 0.01, 0.005]

print("| df | " + " | ".join(str(p) for p in p_values) + " |")
print("|---:|" + "---:|" * len(p_values))
for df in range(1, 31):
    row = [f"{stats.chi2.isf(p, df):.3f}" for p in p_values]
    print(f"| **{df}** | " + " | ".join(row) + " |")
print()
print(": Chi-square critical values by degrees of freedom. {#tbl-chi2-critical}")
