Load the data and count

import numpy as np
import pandas as pd
from scipy.stats import chi2_contingency
from IPython.display import display, Markdown

survey = pd.read_csv("airport_route_survey.csv")

origins = ["Madison native", "Greater Madison native", "Transplant"]
routes = ["North", "Isthmus", "South"]

observed = pd.crosstab(survey["origin"], survey["route"]).loc[origins, routes]
display(Markdown(observed.rename_axis("Origin").to_markdown()))

observed stays a pandas DataFrame here. Keeping the labels attached is a real advantage over the bare numpy arrays of the previous lesson, since results can be labeled without extra work.

The hypotheses are unchanged:

  • \(H_0\): The route a traveler takes to the airport is independent of where the traveler is from.
  • \(H_1\): The route a traveler takes to the airport depends on where the traveler is from.

The one-line test

result = chi2_contingency(observed)
for i, attr in enumerate(result):
    print(f"{i}: {attr}")

1: 1.4789535918079533e-08
2: 4
3: [[14.8  39.59 56.61]
 [ 9.6  25.68 36.72]

That is the whole test. The function takes the table of observed counts (a DataFrame or a numpy array) and returns a result object with four named parts.

print(f"Chi-square statistic: {result.statistic:.4f}")

Chi-square statistic: 42.2522
Degrees of freedom:   4
p-value:              1.48e-08

These match the values found by hand and with loops: \(\chi^2\) = 42.2522, \(df\) = 4, and \(p\) = 1.5e-08.

Unpacking the result

The result also behaves like a plain tuple, so you may see older code such as:

chi2, p, dof, expected = chi2_contingency(observed)

Named attributes (result.pvalue) are easier to read and are the better habit in new code.

Check the assumptions

The chi-square test is an approximation, and it works well only under some conditions. Before trusting the p-value, check:

  1. Two categorical variables. Yes: origin and route.
  2. Independent observations. Each respondent appears once and answers once. (This is a matter of study design, not something code can check.)
  3. Adequate expected counts. A common rule of thumb is that every expected count should be at least 5.

The third condition is easy to check because the function already returned the expected values. We wrap them in a DataFrame with the same labels as the observed table.

expected = pd.DataFrame(
    result.expected_freq, index=observed.index, 
    columns=observed.columns)

display(
    Markdown(
        expected.rename_axis("Origin").to_markdown(floatfmt=".2f")))
print(f"Smallest expected count: {expected.to_numpy().min():.2f}")
print(f"All expected counts >= 5: {(expected >= 5).to_numpy().all()}")
Smallest expected count: 9.60
All expected counts >= 5: True

The smallest expected count is 9.60, comfortably above 5, so the approximation is fine.

When expected counts are too small

If some expected counts fall below 5, consider combining sparse categories, collecting more data, or (for a 2 × 2 table) using Fisher’s exact test, scipy.stats.fisher_exact().

What about the “correction” argument?

chi2_contingency() has a correction=True default. It applies Yates’ continuity correction, but only when the degrees of freedom equal 1 (a 2 × 2 table). For tables larger than 2 × 2, such as this 3 × 3 table, it changes nothing.

Which cells drive the result?

A significant chi-square statistic says something differs from independence, not what. To find out, look at the standardized (Pearson) residuals:

\[ \text{residual} = \frac{Observed - Expected}{\sqrt{Expected}} \tag{1}\]

Residuals beyond about ±2 stand out, since values in that range would be unusual under independence. The sign tells you the direction: positive means more than expected, negative means fewer. Squaring each residual gives the normalized squared errors from the earlier lessons, so these are the same building blocks.

residuals = (observed - expected) / np.sqrt(expected)

display(
    Markdown(
        residuals.rename_axis("Origin").round(2).to_markdown(floatfmt=".2f")))

Reading Table 4:

  • Madison natives took the Isthmus route more than expected (residual above +3) and the South route less than expected (below −3).
  • Greater Madison natives took the Isthmus route less than expected and the South route more than expected.
  • Transplants are much closer to what independence predicts.

A heat map makes patterns like this easier to see. The .style accessor in pandas can color a table without any plotting library.

residuals.round(2).style.background_gradient(
    cmap="RdBu_r", vmin=-4, vmax=4).format("{:.2f}")

How big is the effect?

With a large enough sample, even a tiny departure from independence is “significant.” So a p-value alone does not tell you whether a relationship matters in practice. An effect size can give more nuance to the interpretation. For chi-square tests, a standard choice is Cramér’s V:

\[ V = \sqrt{\frac{\chi^2}{n \times \min(rows - 1,\ columns - 1)}} \tag{2}\]

V runs from 0 (no association) to 1 (perfect association).

n = observed.to_numpy().sum()
k = min(observed.shape) - 1

cramers_v = np.sqrt(result.statistic / (n * k))
print(f"Cramér's V: {cramers_v:.3f}")
Cramér's V: 0.265

A common guide for interpreting V depends on the smaller table dimension, as shown in Table 6. Here min(rows − 1, columns − 1) is 2.

With V = 0.27 and a smaller dimension − 1 of 2, the relationship is somewhere between medium and large. The result is not only statistically significant but also substantial.

Wrap it in a function

Once you have done the analysis a few times, put the routine parts in a function so that any pair of categorical columns can be tested with one call.

def chi2_report(data, row_var, col_var, row_order=None, col_order=None):
    """Run a chi-square test of independence on two categorical columns."""
    table = pd.crosstab(data[row_var], data[col_var])
    if row_order is not None:
        table = table.loc[row_order]
    if col_order is not None:
        table = table[col_order]

    res = chi2_contingency(table)
    expected = pd.DataFrame(
        res.expected_freq, index=table.index, 
        columns=table.columns)

    n = table.to_numpy().sum()
    v = np.sqrt(res.statistic / (n * (min(table.shape) - 1)))

    return {
        "observed": table,
        "expected": expected,
        "residuals": (table - expected) / np.sqrt(expected),
        "chi2": res.statistic,
        "dof": res.dof,
        "n": n,
        "p": res.pvalue,
        "cramers_v": v,
        "min_expected": expected.to_numpy().min(),
    }
report = chi2_report(survey, "origin", "route", origins, routes)

print(f"chi2({report['dof']}, N = {report['n']}) = {report['chi2']:.2f}, "
      f"p = {report['p']:.2e}, V = {report['cramers_v']:.2f}")
chi2(4, N = 300) = 42.25, p = 1.48e-08, V = 0.27

Because the function takes column names as arguments, we can reuse it immediately on a different question. Here we check the survey against itself with the roles of the variables swapped. The chi-square statistic is symmetric, so the answer is the same.

swapped = chi2_report(survey, "route", "origin", routes, origins)

print(f"chi2({swapped['dof']}, N = {swapped['n']}) = {swapped['chi2']:.2f}, "
      f"p = {swapped['p']:.2e}, V = {swapped['cramers_v']:.2f}")
chi2(4, N = 300) = 42.25, p = 1.48e-08, V = 0.27

Make the decision and write it up

The decision rule is the same as before: If the p-value is below the significance level (conventionally 0.05), reject the null hypothesis.

alpha = 0.05
print("Reject H0" if report["p"] < alpha else "Fail to reject H0")
Reject H0

A typical write-up for a report or manuscript states the statistic, the degrees of freedom, the sample size, the p-value, and the effect size:

A chi-square test of independence found a significant association between where travelers are from and the route they take to the airport, \(\chi^2\)(4, N = 300) = 42.25, p < .001, Cramér’s V = 0.27. Madison natives took the Isthmus route more often than expected, and Greater Madison natives took the South route more often than expected.

What this does and does not tell you

Rejecting the null hypothesis tells us the two variables are related. It does not show that where a person is from causes their route choice, and it says nothing beyond the population that was sampled. Remember also that the data here are fictional, and the Data Maker page deliberately built the relationship into them.

Which approach should you use?

## Wrap it in a function

Once you have done the analysis a few times, put the routine parts in a function so that any pair of categorical columns can be tested with one call.

```{python}
def chi2_report(data, row_var, col_var, row_order=None, col_order=None):
    """Run a chi-square test of independence on two categorical columns."""
    table = pd.crosstab(data[row_var], data[col_var])
    if row_order is not None:
        table = table.loc[row_order]
    if col_order is not None:
        table = table[col_order]

    res = chi2_contingency(table)
    expected = pd.DataFrame(
        res.expected_freq, index=table.index, 
        columns=table.columns)

    n = table.to_numpy().sum()
    v = np.sqrt(res.statistic / (n * (min(table.shape) - 1)))

    return {
        "observed": table,
        "expected": expected,
        "residuals": (table - expected) / np.sqrt(expected),
        "chi2": res.statistic,
        "dof": res.dof,
        "n": n,
        "p": res.pvalue,
        "cramers_v": v,
        "min_expected": expected.to_numpy().min(),
    }
```

## Summary

1. Build the observed table with `pd.crosstab()`.
2. Pass it to `chi2_contingency()`. Read `statistic`, `pvalue`, `dof`, and `expected_freq` from the result.
3. Check that the expected counts are at least 5.
4. Inspect standardized residuals to see which cells drive the result.
5. Report an effect size such as Cramér's V alongside the p-value.
6. Wrap the routine in a function for reuse.
7. If the p-value is less than 0.05, reject the null hypothesis. Otherwise, fail to reject it.
